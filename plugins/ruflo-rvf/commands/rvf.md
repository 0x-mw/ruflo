RVF memory management:

1. Call `mcp__plugin_ruflo-core_ruflo__memory_stats` to get storage metrics
2. Call `mcp__plugin_ruflo-core_ruflo__session_list` to show saved sessions
3. Present: total entries, namespaces, storage size, saved sessions, last backup time
